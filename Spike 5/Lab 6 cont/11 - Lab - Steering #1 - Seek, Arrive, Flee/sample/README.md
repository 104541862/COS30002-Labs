This code features the pursuit extension. 

To spawn a yellow evader agent, hit SPACE. It will not conform to any arrive or flee modules (since fleeing from the hunter would just have them both going in a straight line forever, owing to the toroidal design of the map...) and instead just seeks the target (the red star) automatically.

To change the seeker's modes, hit the following keys:
1 - Seek
2 - Arrive (slow)
3 - Arrive (normal)
4 - Arrive (fast)
5 - Flee
6 - Pursuit (pursues the yellow evader, only if it is on screen.)
